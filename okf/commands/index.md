# Commands

Slash commands registered by the plugin (skipped if the user already defined the same name).

* [okf-init](okf-init.md) - Initialize an evidence-backed OKF bundle
* [okf-update](okf-update.md) - Update from repo, git diff, or session
* [okf-validate](okf-validate.md) - Validate a bundle; optionally fix
* [okf-compact](okf-compact.md) - Compact logs, or whole bundle with `all`
