# Commands

Slash commands registered by the plugin (skipped if the user already defined the same name).

* [okf-create](okf-create.md) - Create an evidence-backed OKF bundle
* [okf-update](okf-update.md) - Update an existing bundle from repository evidence
* [okf-capture](okf-capture.md) - Capture durable knowledge from the current session
* [okf-validate](okf-validate.md) - Validate a bundle; optionally fix
* [okf-compact](okf-compact.md) - Compact log files to durable knowledge
* [okf-diff](okf-diff.md) - List files changed since a git ref
