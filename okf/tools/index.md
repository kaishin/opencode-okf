# Tools

Deterministic tools exposed to OpenCode agents.

* [okf_validate](okf_validate.md) - Validate an OKF bundle with v0.2-aware field checks
* [okf_capture](okf_capture.md) - Append a session capture entry to root log.md
* [okf_diff](okf_diff.md) - List git changes for scoping bundle work
* [okf_inspect](okf_inspect.md) - Inventory likely knowledge sources in the repo
* [okf_init](okf_init.md) - Create missing reserved OKF files without overwriting
* [okf_spec](okf_spec.md) - Fetch the authoritative current OKF specification
